# 阶段一审计的适用范围

阶段一的 `MANIFEST.json` 和四份输出保持原样，供复核当时的推导与实验。它验证了**同槽、共同质量/效率、无逐目标衰减**条件下的可行集合；没有部署策略，也没有新的完整赛季分数。

后续公开协议审查发现两项部署差异：

1. 阶段一用公开参考包的 truth 槽表定位时间边界。正式运行应从 initialize 的夜间日历、`slot_seconds` 和已到达 bulletin 推导边界，并验证一致性。槽的时间可由公开信息重建，但阶段一代码本身不是只读取参赛接口的实现。
2. 阶段一使用至少三个正分、65°以上目标作为清洁曝光筛选。terrain 的高度和角宽范围并非 initialize 的固定保证；长曝光可能部分受遮挡，仍产生正分。因此“全部参考样本包含真实 C/E”不能证明这个筛选对任意正式卡均成立，两处自然档位集合缩小也不能直接部署。

正在单独检查两种严格替代：允许任意逐目标衰减时，分数严格高于 mismatch 上限仍能证明 program 匹配；或在完整单槽、无其他事件、单个积分采样点的短曝光中，用正分排除永久 terrain 的二值遮挡。后者还需核验公告覆盖、报告修复、配置与舍入条件。

阶段二源码、证明和结果另存于 `stage2/`。本文件只补充阶段一限制，不改写旧实验结果，不把信息增益计作科学奖励或完整赛季收益。
