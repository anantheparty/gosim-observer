`observations.csv` 每个 score 六位舍入带来的单目标最大值误差不超过 0.0000005，因此科学总分界为 `0.0000005 × 有效账本中不同目标数`；总分界再加官方 total 六位舍入误差及浮点裕量。未出现完成阈值歧义，因此没有额外 50 分或 100 分跳变误差。各 JSON 同时验证官方 observations/decisions/messages SHA256，所有错误界都覆盖实际差异。

## 全局求解剩余障碍

1. 当前 best 的 required missing 为 α 3、β 9、γ 3、δ 6，合计 21 个；仅这一分项存在 1050 分的形式奖励空间，但可见性、玻璃格、曝光时长、其他赢家被替换及 REQ 窗口的机会成本尚未证明能兼容，不能把 1050 计为可实现改善。
2. γ/δ 冻结 prefix 的 suffix 主模型是可信的有限子问题，不能证明完整调度全局最优。要放开 prefix，需将 observe-count/rank 与 data-loss、触发送达决策边界共同纳入状态，或完整重放候选。
3. 科学 max、mandatory completion、REQ distinct quorum 是不同耦合项。每目标 winner 层不能替代最大 factor 层；单卡单目标 witness 的存在不能保证联合可行。
4. Jain 项会随完成分布变化。整数模型如只优化科学/required/REQ，可以作为代理目标，但 candidate 最终必须重新结算 Jain；LP 中删除非正 Jain 项只能得到该有限列集合的乐观界。
5. 新观察列的质量与程序 band 还依赖真实天气、修复状态、方向事件及实际 pointing offset；公开消息反演是条件证据。有限网格价格最高值没有覆盖连续指向、任意时长和所有报告/rank 历史，不能给出完整全局上界。
6. GPU 批量列定价的加速与官方总分改善是两项证据。此次审计没有运行 GPU 或产生新调度得分；900 秒 wallclock 预算及远端通信能否成功仍需独立验证。

`{card}.json` 保存全套结算、每个请求的完成 witness、状态前缀、原失效区间、可交换区域和天气对比。`{card}_target_ledger.json` 保存所有公开目标的 best score、最大 factor、完成 witness 和 CSV 科学 winner；用于迁移模型、排查原赢家被新列替换的机会成本。CSV 科学 winner 的微小舍入同分只是导出级别并列，不代表原始浮点精确同分。
