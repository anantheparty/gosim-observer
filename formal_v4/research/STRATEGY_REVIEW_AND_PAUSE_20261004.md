## 三、可能更根本的方向偏差

以下分为已知数学结构与有待证实的解释。不能由一次负结果直接指定训练失败的唯一原因，也不能由一次正代理差额判定终局策略已改善。

### 1. 终局最高分改变了重复观测的价值

science 结算按目标在有效条目中的最高 **program-multiplied score** 取值。当前目标 best 为 B、某次贡献为 C 时，单次增量是 `(C−B)+`；随机未来的终局对象则是：

`E[ max(B, C₁, C₂, …) − B | public history, policy ]`。

先对 C 取均值、再取最高值通常会改变这个目标。随机复访可能保留“首次不好、后来补足”的价值；不同曝光的天气相关性又决定这种补足有多大。确定固定系数下删除弱重复指派是合法化简，随机未来不能据此把每个目标永久限为一次。

此外，required/REQ 使用 raw factor，Jain 使用终局覆盖计数，science 使用最高 score；它们可以由不同曝光见证。data loss 还能撤销原最高条目。将这些状态合并成单个“已观测/完成”标记，或只追踪预计总 science，会丢掉真实控制需求。[共同情景与得分层模型](STOCHASTIC_PATTERN_MODEL_ZH.md)已经写清这一边界，尚未提供完整正式策略收益。

### 2. 单次 marginal 没有给出 joint future

预测一条曝光的条件分布，可以正确计算该动作的 `E[(C−B)+]`。对一个事先固定的合法 assignment，期望加法也不要求各目标独立。这是有用而明确的局部对象。

然而，后续哪一次值得再看、哪些目标争同一个时间/field/fiber、一次反馈会怎样改变后续动作，都需要跨曝光的共同未来结构。各动作孤立的边际分布不能决定终局 Emax。独立重抽每个动作的天气，还可能制造并不存在的复访分散效果；在每个 future truth 中先选最优动作再平均，则会授予策略未来信息。

我们多次改善了当前曝光的积分与结算，却仍缺少可靠的“当前选择如何改变未来共同资源与有效账本”的对象。这个缺口不一定靠更大的 marginal NN 解决。

### 3. 候选域和教师行为可能先限制了可学内容

优化器只能比较生成出来的动作。三夜 rollout 的不同 field 仍来自即时排名菜单；若释放未来资源的动作没有进入菜单，更长续局也无法选它。全季固定图的小时网格与三种时长会改变时间容量；图内求解更强，不等于已经搜索实际完整动作域。

教师标签同样有边界：执行某一固定 B 后的反事实终分，学到的是该后续行为的价值 `Q_B`。它既不是全局最优价值，也未必覆盖换策略后出现的 history。少量公共状态、很少活动 REQ、control-only/tie 数据和相近候选，可能不足以揭示真正的替换链。大量相关 target rows 也不能替代足够多的独立 world 与行为状态。

因此值得区分“模型未学会已有标签”与“标签和候选没有表达想改变的决策”。直接分布 NN 的负 validation 证明当前组合未成功，但现有证据尚不能把这两种解释分清。

### 4. 官方生成器数据仍可能与线上状态分布不同

同公开配置、同官方生成器，并不意味着新生成数据覆盖当前强策略会走到的全部状态。目录规模、flux/weight、曝光长度、饱和与复访比例、方向事件、预报发布时间、故障反馈和请求关系都影响条件分布。固定采样几何与强策略自选曝光之间还存在行为偏移。

公开目录与隐藏天气使用不同命名随机流；粗预报提供支持信息，却不公开精确天气、强度和全部边界。没有恢复实际隐藏 seed，也没有证明训练世界等于线上未知世界。未知信息应保留为条件分布，已公开支持应作为约束使用。见[公开与隐藏随机状态研究](cold_public_rng_20261004.md)。

### 5. 报告与故障控制具有真实 continuation 成本

一次 report 影响免费额度、健康时点、修复收益、随后观测和 belief 更新。false 在当时也提供健康证据，但可能消耗留给以后故障的额度。有限 sensor DP 若省略原 controller 的 witness、cooldown、等待行为和故障持续/renewal 状态，其 Bellman continuation 会与实际程序不同。

L3 report 组合的失败已有具体链条：early false 消耗免费额度，后续修复路径受到影响；移除 report 后物理动作与原 strong 对照相同。该证据比“NN 概率不准”更具体，却仍不能从一个 posterior scalar 推出完整控制价值。见[report 实际因果记录](../results/sparse_report_actual_20261004/ROOT_L3_PUBLIC_CAUSAL_TRACE.json)。

closure 的负结果也说明，增加合法观测会改变后续反馈、排程和 observe rank；更多覆盖不自动变成更多有效最高分。报告、观测和损失不是可以各自加一个分数后独立优化的模块。

### 6. 代理目标与最终采用条件仍有距离

NLL、当前 gain/秒、固定图整数 ledger、覆盖目标数和 LP 上界，各自有用途。它们没有相同的采用含义。native 同动作省CPU为资源提供了空间；如何使用这部分空间取得收益仍是另一个问题。更低预测损失也未必改变有价值的动作，而一个正确的局部规则可能令整季分数下降。

这里需要保持清楚的证据链：接口与物理合同 → 同候选域的实际决策比较 → 完整公开闭环的总分与组件 → 线上实际评测。固定模型出现真实整数改善可以作为机制信号，不必等宽松上界闭合；其转为比赛策略的有效性仍须单独建立。本轮 partial 尚未走完整这条链。

## 四、留给暂停期间的三个建模取舍

### A. 把终局有效账本和共同未来作为战略对象

可以思考：是否让战略层围绕 score layers、随机复访、共享 field/fiber/time 以及损失后的有效 ledger 建模，当前曝光分布作为其中的物理输入。未知未来以共同情景或联合隐状态表达，并坚持相同公开 history 下只能选择一个共同动作。REQ/required/Jain/report 是否需要保留显式状态，而不是吸收到单个即时 utility 系数中。

### B. 先确认候选与标签包含真正想改变的决策

可以思考：需要学习的是未知物理、行为续局价值，还是跨时间资源价格；现有候选是否包含低即时收益但释放未来竞争的动作；教师是否足以评估这些动作。已知几何、积分、flux、cap 与 program 可继续由解析算子处理，学习对象尽量对应仍未知且会改变决策的部分。新商模型的数据已经保存，但目前没有训练结果来支持选择它。

### C. 让组合求解与统计推断承担各自可验证的部分

固定路径匹配、合法几何、区间 DP 和稳定价格仍能精确或高效处理明确子问题；partial 结果没有否定这些工具。统计模型需要表达公开信息下的不确定性及真实行为分布。两者结合时，应明确哪一层是可证的确定优化，哪一层是概率近似，以及最终策略受到哪些候选和运行预算限制。

这三条是供用户思考的取舍，不是已批准的新启动计划。当前没有选择下一条路线、分配新算力或安排自动继续。
