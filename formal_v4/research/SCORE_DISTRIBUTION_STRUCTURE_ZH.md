# 得分分布的物理结构与下一步假设

2026-10-04。以下是从官方评分公式推得的结构，以及尚未验证的研究假设。当前 `cold_target_score_distribution` 的冻结训练不作修改，不能把本节假设写成其验证失败的已证原因。

## 1. 复访应计算分布上的正部

某目标已有有效科学贡献 B，新贡献为随机变量 S，科学增量是 `(S-B)_+`。必须计算 `E[(S-B)_+]`，不能用 `(E[S]-B)_+` 替代。后者通常更小。例：B=2，S以相同概率取0和4，真实期望增量1，而先平均再取正部得到0。

对固定曝光、每 fiber 独立选一个目标的科学加性目标，可以先逐目标算该期望，再逐 fiber 取最大。期望的线性性不要求目标之间独立。这个结论不覆盖请求门槛、Jain、未来失效、信息价值或多次曝光的自适应策略。

## 2. 已知的缩放可以从学习对象中消去

令 `H_i(t)=lunar_i(t)/airmass_i(t)^airmass_exponent` 为公开几何因子，`C(t)=transparency(t)*sky_quality(t)/(seeing(t)*q0)` 为全局天气质量，`E(t)` 为设备效率，`D_i(t)` 为目标方向上的事件衰减。不可观测片段的积分贡献为0。实际 integration 使用官方分段和采样规则。令 d 为已经按夜末和季末裁短的实际时长。

官方物理 factor 可写为

```
F_i = min(1, flux_i / (flux_zero * exposure_zero) * I_i)
I_i = sum_piece seconds_piece * H_i(sample) * C(sample) * E(sample) * D_i(sample)
```

actual band 从不含设备和方向事件项的天气质量积分与阈值导出，独立于目标 flux、科学权重和 declared program。命中且当时有效的贡献是 `weight_i * F_i * multiplier(declared, actual_band)`；未实际命中不产生贡献，后续公开回溯失效还会改变有效账本。这里的F仅为物理factor，几何命中处理仍在外层。

取一个仅从公开网格和几何计算的正数 `Hbar_i`，定义

```
R_i = I_i / (d * Hbar_i)
s_i = flux_i * d * Hbar_i / (flux_zero * exposure_zero)
F_i = min(1, s_i * R_i)
```

这是代数恒等式。隐藏事件切点改变 integration mesh 时，其影响包含在 R 中，不能假称 Hbar 消除了未知切点。Hbar 必须按同一公开初始化、目标、时间和实际时长计算；为0的边界需单独处理。

因此可以研究 `(R_i, actual_band)` 的条件分布，让公开缩放、饱和和科学权重留在精确公式中。模型输入可移除 flux；给定相同其他物理条件，它的输出分布不随 flux 或 weight 改变，F 对 flux 的单调性自动成立。当前直接 F 的195类模型需要自己学这些关系，没有强制这些不变量。

该变换尚未验证会提分。R不再天然限于[0,1]，不能直接沿用F的65个均匀节点或原量化误差界；需要新的尾部、节点或连续混合分布设计。F=1的公开测量只给R下界，不能在actor中反推未截断真值。新独立生成世界的host可以提供未截断积分训练标签，但这些标签不得进入actor。

## 3. 与跨夜算法的连接边界

新完整曝光模式列生成已在固定确定系数的小实例改变首动作，并降低LP内存。其等价证明依赖确定贡献。将每次未来贡献替换为NN均值，不能得到随机多次观测 `E[max(S_1,...,S_k,B)]` 的精确模型或全局上界。

下一研究应明确选用哪一种对象：单步条件期望增量、固定联合天气情景下的共同排程，或能根据未来公开反馈分支的滚动策略。必须保留同一目标的best竞争、曝光时间冲突和每fiber容量，才能判断质量提升与未来机会损失的取舍。

## 4. 实验纪律

本轮12+12个checkpoint按既有规则跑完，不据中途负值改结构或打开测试。上述结构变换是后续独立实验假设。先验证新标签、输出与官方公式的接口，再声明数据划分和选模规则；只有正常完整赛季与原强策略的同卡比较能说明比赛提分。
