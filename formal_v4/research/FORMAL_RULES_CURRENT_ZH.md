# 正式规则核对（2026-10-03 20:31 JST）

来源：官方 [规则](https://create.gosim.org/survey26/platform/rules)，页面标注版本 **2.0 / 2026-10-01**；同时查看官方资源页。通过已登录 Chrome 的正常页面读取，没有读取隐藏接口。

## 当前适用机制

- 练习赛 α–δ，正式线上 A–D，截止后隐藏决赛 E–H；均为每卡整季、每卡 **900 秒**真实时间，从第一条决策请求计时，包含程序与平台处理。
- 正式线上 A–D 固定且对所有队伍相同。公开目录、日历、站点、仪器、评分配置；未来天气、预报、事件与故障保密，只逐轮提供当前信息。
- 一次线上评测取四卡平均，四卡均评分后入榜，保留最好一次完整批次；不能用不同批次的单卡最高分拼接线上成绩。
- 最终排名只取未见过的 E–H 四卡平均，线上成绩不决定奖项。固定练习排程只能帮助固定实例研究，未知卡仍需在线算法。
- 线上阶段：北京时间 2026-10-05 00:00 至 10-07 23:59；截止后评测隐藏卡。
- 平台容器 **2 核 CPU、2 GB 内存**。允许自有服务器和外部服务；每轮必须由程序自动决定，不能人工代为决策。
- 正式提交完整源码项目；公开 GitHub 或私有 ZIP（≤50 MB）；不接收 CSV 作为正式提交。
- 模型 API 是可选运行设置；其配置地址须为公网 HTTPS 域名（默认 443），不接收 IP/内网地址。按我们的实际网络检查，目前自有 GPU 路由仍未能从平台连通，不能把本地 GPU kernel 的速度直接当线上端到端速度。
- 评奖另要求至少两个大模型驱动环节；本项目按用户选择以纯算法最高分为目标，未申请该奖项资格、未填写设计备注。
- 额度按参赛页为准、UTC 0 点重置。此次页面显示每天8次，开始缓存版后剩6次；不是永久固定规则常数。

## 练习数据公开文案与实际下载

规则文字称练习卡全部文件（含天气、预报和事件）公开。不过在上述时刻从资源页正常重新下载 α，ZIP 仍只有六个公开输入文件，与之前档案逐字相同，没有真值产品。见 `results/public_practice_download_refresh_20261003/`。不能依据文案直接认定本地拥有完整 α 真值，也不推断任何隐藏卡数据。

## 固定排程基线的用途

把自己此前合法评测得到的动作固定成逐轮执行程序，可以移除重新搜索导致的差异，并供离线数学模型输出新排程。仍须每轮收到当前请求后再回复一个动作，保持原曝光编号、等待和报告时刻；不改已接受动作、不调用隐藏接口。只有一次新的完整官方回放才构成新包实测成绩。

公开卡身份一致不能单独证明全部隐藏天气真值身份一致；当前自己的共同曝光只能验证对应时间与目标的数值一致。条件质量模型、有限列 LP 上界、固定实例排程和未知卡在线策略需分别记录适用范围。
