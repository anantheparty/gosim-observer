# 同天气槽的程序差异能否破除质量档位别名

2026-10-04 JST。范围：独立逆问题研究；只读官方评分器/生成器和既有离线轨迹，新增本研究文件。不修改生产，不进行平台动作，不使用 runtime LLM。

## 机制

一个 900 秒天气槽中，若没有未建模的方向损失、关闭或中途修复，令 `C=transparency*sky/(seeing*q0)`，`E=instrument_efficiency`。目标 i 的公开几何积分为 `H_i=mean(lunar/airmass^.6)`，`a_i=flux_i*T_i*H_i/(f0*t0)`，公开归一化分 `y_i=score_i/weight_i`，则

`y_i=min(a_i*Z,1)*m_i(C), Z=C*E`。

`m_i(C)` 只在 `.4/H_i` 与 `.65/H_i` 改变。固定一个倍率模式时，任何满足阈值区间的 C 都可配以 E=Z/C 产生相同未饱和分数。因此有限观测通常只能识别 Z、离散倍率模式和 C 区间，不能精确识别连续 C/E。减少拟合残差不能解决这种等价。

不同声明程序的同槽观测共享 C/E，且各目标 H 可以不同。只有 actual band 相同且未饱和时，DARK/BRIGHT 两次归一化比值才限于 `1.2`、`1/1.12`、`1`。一般情况必须联合枚举所有目标的阈值区间；不假设两个曝光 actual band 相同。

## 可否证预声明（在轨迹审计前锁定）

1. 同槽联合集合反演必须在标准模型的人工样例中保留真值，且当单曝光存在高 E 别名时，多程序信息可排除该别名。故意跨槽改变 E 或 C 后必须识别无可行共同状态，而不能返回虚假的精确证书。
2. 对既有 L1/L2 轨迹，只将完整处于同一槽、score 有正值、没有方向/地震等混杂的曝光用于机会审计。H 采用官方 lunar 与 airmass、相同的 <=120s 积分，而不是曝光起点。公共输入只取 target_id/score；离线 factor/quality/prog_mult 仅用于之后验证，不作为反演输入。
3. 每个槽的曝光逐次加入后，若与只看当前曝光相比，联合状态首次得到 `E_upper<.8`，记录为新效率证据。另记录联合状态能否在无费用的自然 program 改变中缩小未来行动的 band 集合。记录事件混杂、跨槽和不可行槽，不能用残差容错猜档。
4. 第一阶段成功标准是找到真实可执行的信息差异，不能称为整季提分。若没有自然证据，或共同状态假设在合格槽经常失败，则停止这条最小路线。若存在机会，下一阶段需要冻结公开触发规则并用真实 continuation/replan 比较 science/required/REQ/report/总分，先报告根代理再使用空闲 cores4–7。

## 主动 probe 的代价

最短曝光 60 秒；probe 可以复用上一 exposure 的 sky field 并追踪固定 RA/Dec，保证同 target 相比时的 H 已知，但必须重新计算 fiber 指派与高度窗口。禁止跨900秒槽。声明另一 program 的代价来自科学倍率与占用时间，而不是只比较即时 score：终局 best-only ledger 可恢复部分小曝光分数，但不能退款时间。信息收益应为不同可行状态下未来动作价值的差，或经验证可提前修复效率异常的收益；不能用 C/E RMSE 下降替代。

现有 `feedback_model.py` 逐曝光用 prior 选择一个 C/E 模式，`efficiency_bounds.py` 仅用 `score/weight>1` 的单目标匹配证据。现有生成器诊断路线使用 point-fit 的低 E 和免费报告，强 phase 上失败；已有完成证书 program 切换也失败。本研究的新差异是同槽多曝光的完整可行集合和自然/短时 program 差异，先证明识别边界。
