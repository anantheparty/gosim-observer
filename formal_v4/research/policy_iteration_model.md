# Independent policy iteration model, 2026-10-04

Written after directly reading official v4_runner.py, v4_scorer.py, v4_fiber_map.py, participant-guide.en.md and L1-L4 public/config products, before reading the algorithm portfolio or prior neural teacher scripts.

## Objective and state

Finite season semi-Markov control. An action changes simulated time, future public-message arrivals, the valid raw exposure ledger, observe rank, fault repairs and report allowances, request completion windows, and geometry opportunities. The terminal objective is exactly the official runner total: sum of per-target maximum valid SCORE, minus required penalty based on independent maximum valid FACTOR, minus Jain penalty across RA completion fractions, plus report settlement and issued request reward. Request exposures must be wholly contained in request issuance/deadline. A data_loss window invalidates exposure ranks [floor(i*N),floor(j*N)); N itself depends on previous durations, waits and decisions. No fixed suffix relabeling can represent these effects.

Decision features may consume only initialize data, delivered public messages, submitted historical actions, received scores/hit sets, resync windows and geometry derivable from public calendar/site/targets. Factor is not delivered; maintain uncertainty or conservative factor bounds from score/weight and public program multiplier possibilities. Never insert runner truth factor, unreleased messages, hidden offsets, future weather, hidden seed or scenario truth into features.

## Teacher

At a selected real native decision state s, clone the entire teacher state INCLUDING RNG and raw public-history ledger before planning. Get baseline action a0 and legal candidate actions generated by the same native geometry planner. Branch each candidate action once; commit that exact action as teacher's previous-action state, then resume the frozen complete native planner after every resulting runner public feedback until season end. Baseline control also continues naturally and must reproduce original baseline score/components/action stream. Offline runner alone has hidden truth and terminal labels. Candidate generation must not condition on counterfactual feedback or terminal score.

Full branch value Q_pi(s,a) is final official score after a + natural pi continuation, not immediate gain. Pair label is Q_pi(s,a)-Q_pi(s,a0). Preserve terminal decomposition, missing required count, request statuses, Jain bands, total observe rank, and invalidation records, plus suffix action divergence count/hash.

## Predeclared coverage

Before reading branch labels, select states from stratified season fractions [0,.25),[.25,.5),[.5,.75),[.75,1]. Within each quarter separately cover active request, required-near-threshold, clean/no-request, public adverse bulletin, and post-resync when available; unavailable strata are recorded. Do not use future hidden event time. Select deterministic hash minima of public prefix+state id, at most 2 states per quarter/available stratum/card. Proposed full budget: 16 states/card * 4 cards * 5 branches = 320 complete seasons (including baseline branch); strict pilot first: one L1 early clean state, baseline/control, one distinct field, one changed duration, one changed program. Candidate set must include baseline plus near-ranked alternative field(s), shorter/longer duration with remapped assignments at same start, and public-band alternative. Exclude duplicate exact action hash; record rejected alternatives.

## Student and split

Initial student: permutation-invariant target/action encoder, target nodes from public attributes, score/factor bounds and geometric remaining support; action nodes from per-fiber assignments/duration/program and expected physical outcomes; sum/max/count pooling plus global ledger/REQ/Jain/RNG-free belief/rank/time features. Score scalar V(s,a), train pair differences with Huber loss on raw full-season score delta and auxiliary component deltas. Include baseline anchoring and confidence/abstention when heldout calibration fails. Flat pooled MLP is a useful first implementation before graph message passing.

Entire-state groups must stay together; final card split train L1/L2, validate L3, untouched test L4, with time-block-heldout within training cards only for fitting diagnostics. No random pair split. 256 distinct training states is a minimum for broad policy claims; 1 pilot group only validates plumbing. Positive/negative/tie ratios are measured and saved, never filtered by advantage. Runtime no LLM; student inference uses public state, small fixed NN and bounded candidate set.
