# 未知天气下的最高分：情景、得分层与曝光模式

2026-10-04。这是对已完成确定性曝光模式 LP 的数学扩展，尚无新求解或正式赛收益。目的是保留随机复访价值，而不是将天气均值代入 `max` 后沿用每目标至多一次的模型。

## 1. 条件与研究范围

在当前公开历史 h 下，固定一组共同未来情景 s，概率 p_s≥0、总和为1。每个情景是一条完整共享天气与物理轨迹；同一目标的不同曝光、同次曝光的不同目标使用同一情景。仅有各动作的边际分布不足以确定终局最高分。

固定一个有限合法曝光集合 e。曝光的起止、指向、program 已确定，目标在该曝光归属哪个 fiber 由几何确定。对每个候选目标 i，预计算情景 s 下的贡献 c_ies≥0。当前有效最高贡献 B_i≥0 固定，令 g_ies=(c_ies−B_i)_+。

本节暂时固定有效性、仪器与修复控制，忽略未来反馈改变策略的自适应价值。若 data loss 取决于动作序号、未来 report 会改变效率、目标移除或奖励有额外约束，c_ies 不再是独立于选择的固定系数；下面的等价证明不能覆盖那些机制。它也不包含 REQ、required、Jain 或正式全题最优性。

## 2. 为什么确定模型的 target≤1 失效

单目标当前 B=0，两次曝光的贡献独立为0或1，各概率一半。一次的期望贡献为0.5，两次的终局最高贡献期望为0.75。允许复访增加0.25，不能删去第二次曝光而保持期望收益。

目标函数是 `Σ_i E_s[max(B_i, selected c_ies)−B_i]`。通常它不同于 `Σ_i (max_e E_s[c_ies]−B_i)_+`。后者先取均值，丢失了共同情景及复访期权。

## 3. 精确的有限情景得分层模型

对每一对 (i,s)，把所有正 g_ies 的不同值排序为

`0=a_is0<a_is1<…<a_isL`，`Δa_isl=a_isl−a_is,l−1`。

对曝光 e，Q_e 是完整合法 fiber assignment 模式集合。一个模式 q 对每个 fiber 选至多一个 fitting target；m_iq∈{0,1}。用 z_eq∈{0,1} 选择整个曝光及其模式。正时长曝光至少覆盖一个时间 atom，共同时间容量隐含同一曝光不能选择两个模式。

令 y_isl∈[0,1] 表示是否覆盖阈值 a_isl，模型为：

```
max  Σ_isl p_s Δa_isl y_isl
y_isl ≤ Σ_eq m_iq 1[g_ies ≥ a_isl] z_eq
y_isl ≤ 1
Σ_eq A_je z_eq ≤ 1                    每个时间 atom j
z_eq ∈ {0,1}, y_isl ≥ 0
```

给定整数曝光选择，右侧为覆盖次数；所有目标系数非负，最优 y 恰好是存在一次达到相应阈值时取1。因此每个(i,s)的层收益望远镜求和为 `max_selected g_ies`，等于终局贡献增量。不同曝光允许重复分配同一目标；本模型没有 target≤1 约束。

这证明有限情景、固定系数、固定候选域的整数模型与期望终局科学增量同值。放宽 z≥0 后得到该有限模型的 LP 上界；不是连续动作、未知真实分布或含动作依赖损失的完整比赛上界。

## 4. 列生成仍有按 fiber 分离的定价

给覆盖约束非负对偶价 q_isl，y≤1 的价 r_isl≥0，时间容量的价 λ_j≥0。对偶条件为：

```
q_isl + r_isl ≥ p_s Δa_isl
Σ_i m_iq Σ_sl 1[g_ies ≥ a_isl] q_isl ≤ Σ_j A_je λ_j
```

目标为 `min Σ_isl r_isl + Σ_j λ_j`。曝光 e 的目标价值是

`V_ie=Σ_s Σ_l:a_isl≤g_ies q_isl`。

所以曝光的最大 reduced cost 为

`P_e=Σ_f max_{i fitting(e,f)} V_ie − Σ_j A_je λ_j`，

每个 fiber 也可选空目标、价值0。保持同一目标在同一曝光只归属唯一 fiber 时，定价仍可按 fiber 分离。用每个(i,s)的层价前缀和计算 V_ie，避免在全图扫描时展开全部层的覆盖矩阵。有限情景中目标值非负，但不意味着未知天气的估计准确。

此前 start-atom 对偶修正也适用：按曝光起点 atom 分组，把该组最大正 residual 加到 λ_start。每个曝光覆盖自身起点，全部模式的对偶约束随之满足。修正后的对偶值只约束这一个固定有限情景模型。

## 5. 得分层量化的误差与成本

完整精确层的行量可达 O(S·E)，其中 E 是 target/exposure edges 数；大型目录不能假定它足够小。可以事先固定得分步长 δ_i，对每个 g 向下取整、向上取整为共同阈值网格，分别构造两个代理。

对于任意固定整数安排及每个情景，最大值与量化最大值相差不到 δ_i。因此：

`lower(schedule) ≤ true(schedule) ≤ upper(schedule)`，

两边各自与真实期望差小于 `Σ_i δ_i`。这个最坏界可能很松，不能把它称有效全题误差。上下代理的最优整数值也包住原有限情景最优整数值；上代理 LP 提供额外乐观界，下代理的整数可行解提供具体安排。

模型行量取决于实际得分范围和步长，不取决于每条 edge 的不同数值个数。全图 pricing 仍须扫描候选曝光和场景；减少层行数不能免除大目录的几何构图成本。可共享同(start,duration)物理积分、同(start,field)fiber incidence及各program系数。

## 6. 与当前研究的连接

已完成的确定性模式 pilot 可以先验证实际目录的几何共享、全季时间价格和计算预算。新的物理商/连续后验研究应提供校准的共同未来情景，不能只输出每次曝光孤立的均值。神经网络若参与，可学习未知物理状态或情景权重；已知flux/geometry/曝光积分与合法指派仍由解析算子处理。

下一次实证要区分：模型内整数价值、模型内 LP 证书、公开闭环完整赛季得分。只有最后一项可以作为采用新比赛策略的直接依据。上述推导没有使用旧未生成的test，也没有修改已冻结失败NN。

## 7. 把时间容量交给精确区间 DP，避免大主 LP

模式列生成不是唯一算法。固定有限候选曝光的起止，把所有端点排序成 DAG；相邻端点有空闲弧，每个曝光是一条开始到结束的弧。给定一个曝光的可加权重，最长路径恰好是最大权重的非重叠曝光安排。也可用 weighted-interval scheduling DP。时间跨度长不要求遍历每秒。

### 7.1 确定 winner-edge 模型

对于以前固定确定 g_ie 的每目标至多一次模型，只把 target 容量做拉格朗日松弛，价格 σ_i≥0：

```
D(σ) = Σ_i σ_i + max_nonoverlap_schedule Σ_e W_e(σ)
W_e(σ) = Σ_f max_{i fitting(e,f)} (g_ie−σ_i)_+
```

固定 σ 时，fiber oracle 给每个曝光的 W，时间 DP 精确给整个日历的松弛安排。若同 start/end 的不同 pointing/program 没有额外物理转移成本，可以先保留 W 最大的弧；这只消去该次固定价格 oracle 的等端点候选，下一次价格改变后重新扫描，不能永久删曝光。

任意 σ 给有限整数问题的上界。最优 DP 路径中目标 i 出现 n_i 次时，一个子梯度是 `1−n_i`；投影更新方向为 `σ_i←max(0,σ_i+α(n_i−1))`。可以限制 `σ_i≤max_e g_ie`：超过这个值时，目标不会产生正的 reduced gain，降到该值不提高 oracle 值且降低常数项。相等零值时选空 fiber，避免计入无收益 assignment。

时间 atom 的 interval 矩阵具有 consecutive-ones 性质，其容量多面体是整数的。完整 assignment 模式在同曝光的 convex hull 也由 fiber simplex 构成。因此充分优化这个部分对偶得到同一个有限 target/time 模式 LP 的值；它不是原整数问题的精确解。每次 DP 提供一个真实时间可行路径，可在该路径内按最高贡献去重、重做指派或进行有预算的整数改善，构造具体下界。

最优对偶和整数下界之间可能有 gap。把 Polyak 步长的下界取成整数可行值并不能保证该 gap 为0或消除振荡；应保留 best dual 和 best feasible，记录停止条件，或使用有盒约束的 bundle/cutting-plane。不能把短期子梯度下降直接称全局最优。

### 7.2 随机得分层模型

对第3节覆盖模型，仅松弛 `y≤Az`，保持 `0≤y≤1` 和时间容量。设 q_isl≥0，w_isl=p_sΔa_isl：

```
D(q) = Σ_isl (w_isl−q_isl)_+
       + max_nonoverlap_schedule Σ_e W_e(q)
W_e(q) = Σ_f max_{i fitting(e,f)} Σ_sl:a_isl≤g_ies q_isl
```

这个公式先独立最大化各 y，再对完整时间路径最大化，任意 q 给有限情景整数上界。可投影到 `0≤q≤w`：超出 w 的价格不再降低第一项，却只提高曝光权重，截到 w 不增加 D。盒内部的子梯度为 `n_isl−1`，其中 n_isl 是所选 DP 路径对该层的覆盖次数；价格最小化更新方向与确定 target-cap 对偶不同。

因此随机复访也可由 **共同情景/得分层 + fiber 分离 + 时间 DAG DP + 凸价格优化** 处理。它保留终局最高分的层覆盖，允许多次观测，核心搜索对象不是64个独立问题或64!排列。尚未实现这条算法；情景误差、得分层规模、全目录几何扫描、转移成本和真实协议机制仍需实际检查。

## 8. 固定时间路径后的指派子问题

2026-10-04 新推导；尚无这项随机算法的实际性能结果。路径中每次曝光的时间、pointing、duration、program先固定，每个曝光的fiber构成一个槽位。合法边是“给槽位j指派target i”。这一分解把时间路径搜索和路径内部指派分开，但不把整个赛季化成匹配。

### 8.1 确定贡献：全局加权匹配

固定贡献下，若同target被多个槽位指派，保留最高贡献的一条并删除其余边，科学账本不变、容量仍合法。因此存在每target至多一次的最优指派。左侧为曝光fiber槽位，右侧为target，边权为 `(c_ij−B_i)+`；最大权二分匹配精确求该固定路径的科学指派。程序选择已固定，否则同一曝光的所有fiber共享program，不能各边独立选program。

这解释了为何逐曝光贪心重估可能低估一条时间路径。对旧路径和新路径使用同一匹配器，再分别报告“指派器改善”和“新增时间路径改善”，才能衡量搜索算法的贡献。这个确定匹配化简此前已有，不能当成新发明。

### 8.2 共同随机情景：单调次模目标

设每条合法边e在共同情景s的已固定终局有效增量为 `g_es≥0`，指派边集为A。定义

```
F(A) = Σ_s p_s Σ_i max({g_es: e∈A且target(e)=i} ∪ {0})
```

添加边e的边际是 `Σ_s p_s (g_es−best_is(A))+`。若A包含于B，逐情景的best只增不减，所以这个边际只减不增。故F为归一化、单调、次模函数，不要求各曝光或target的天气独立。情景必须共享同一组未来隐状态；从逐边独立marginal重新抽样得到的是另一个模型。

每个fiber槽位最多一条边，是partition matroid。反复添加全部合法未占槽位中最大正边际的边，有固定有限域最优值的1/2保证：对最优指派O，每条未选最优边映射到占其槽位的贪心边；这些映射一一对应。该最优边在对应贪心步骤仍合法，其当时边际不超过被选边，而末态边际更小。次模性给 `F(O)≤F(A)+Σ_(e∈O\A)Δ(e|A)≤2F(A)`。终止后仍未占槽位的边际为零，不增加该和。

这里允许同target随机复访；单次正边际和确定target-cap消元不能代替它。GPU适合批量计算“共同情景×边”的positive-part边际；CPU可做槽位约束、路径DP和小邻域修复。更多算力应扩大有效共同路径或改善可行整数指派，而不是只算同一宽松界。

### 8.3 适用边界

1/2保证只针对固定曝光路径、固定共同情景贡献和科学账本。它不是完整正式赛、连续pointing域、REQ/required/Jain/report、未知情景分布或反馈自适应策略的保证。尤其data-loss按observe rank，改变路径会改变有效贡献；若留空曝光被省略，连固定路径的rank也会变，必须保持实际动作数量或重新结算。公告、修复、后续feedback会改变合法域和条件分布，不能直接声称adaptive submodularity。
