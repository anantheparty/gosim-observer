# PRO6000 外部搜索：计算收益与比赛计时

2026-10-03。允许外部计算的规则与平台实际出网权限是两个条件；本机 HTTPS 调用成功，但平台免费接口检查实际返回DNS `gaierror`，未进行GPU调用，CPU正常完成公开测试。服务地址与凭据只放在忽略的运行目录和私有提交 ZIP 中。

## 1. 实际链路

评测程序维护观测账本、请求状态、天气信念和指向校准；把公开 initialize、当前 snapshot、自己已获得的分数/保守完成度发送给专用 HTTPS 服务。PRO6000 扫描大量指向、曝光时长和项目组合，CPU 精算筛出的候选，再返回一个动作及其模型预测。

服务只提供 health/initialize/choose/close，凭据检查、请求大小限制、会话限制及锁内串行计算；没有 shell 或读任意文件接口。close 在全卡结束后释放会话，防止多次评测占满会话池。程序不发送也不读取评测器隐藏文件。连接失败后保留本地求解。临时 tunnel 的存活与平台实际允许访问的域名仍是部署条件。

HTTPS 回放完成全季、991 次 observe、1082 次决策；792 次成功 RPC 的累计 wall time 为 868.03s。剩余轮次走本地求解。直接 GPU 回放完成 1006 次 observe、两项请求均完成；HTTPS 只完成其中一项。决策轨迹不同，因此不能把两者分差全部归因于网络。

上述两个 GPU 回放使用较早的同一策略快照。新的日历时钟/维修证据 CPU 四卡均分 6033.564897，其中 L1 为 6096.185388；与旧策略 GPU 的比较并非同源消融。正在进行同源直接 GPU 完整回放。

## 3. 外部调用也是有预算的选择

比赛每卡只给 900s，HTTP 等待同样扣时。设剩余 wall clock 为 W，估计还需 N 次搜索，保守本地每轮代价为 c，完整外部每轮代价为 g，结束预留为 R。可用于增加搜索能力的时间近似为：

```text
B = max(0, W - R - N*c)
外部调用配额 = min(N, B / max(0.05, g-c))
当前外部调用比例 f = min(1, B / (N*max(0.05,g-c)))
```

`remote_budget.py` 用分数配额均匀分配调用：每步累加 f，满 1 才调用。c、g 使用最近 64 次完整 wall time 的 90% 分位；失败等待也计入 g。N 暂以公开剩余夜间秒数比例估算，R=30s。冷启动前采用保守默认成本，外部断连可停用后回到 CPU。

这解决的是有限 wall clock 的预算分配；N 仍是经验预测，90% 分位也不是最坏延迟上界，不能宣称保证不超时。相同平均 1100 轮的合成检查中，外部代价 .45/1.1/2.5 秒时分别调用 999/523/257 次，余时约 436/244/139 秒；完整官方回放才是最终验证。

下一阶段可以用模型收益增量和 LP 时间影子价格决定把配额给哪些轮次。目前只按预算均匀分配，尚未声称得到最优调用安排。

调用配额版已完成 L1：**6174.513257 分、457.197s**，276次 RPC，累计314.566s；CPU完成其余搜索。该版与早先898.64s的版本还包含新的信念时钟/维修证据，不能把163.26分差全部归因于配额控制。

## 4. CD2 独立中转

在用户指定的 CD2 建立独立 HTTPS 路径，nginx 转发到 VPS 的 loopback 19926，再由 PRO6000 所在 WSL 主动建立的受限 reverse SSH 连接到 Windows GPU 服务。该链路不经过原 Cloudflare/Osaka 接入路径。现有网站用一个独立 include 增加新路径，部署前保存备份，nginx配置验证后reload；脚本见 `ops/install_cd2_proxy.py`。

本次 SSH 专用key仅可监听指定loopback端口，禁止shell/PTY/agent/X11使用；本地转发仅允许未使用的localhost端口1。固定使用本机已有、已验证的CD2 SSH host key。key认证有效至2026-10-03 02:00 UTC，连接本身用6小时timeout；正式赛前需要重建或延长专用测试链路。

| 本机发起、同一 GPU 服务 | 原 Osaka 接入 | CD2 |
|---|---:|---:|
| 热连接 health 中位数 | .4624s | .0492s |

两条路径交替测试；冷调用受CUDA JIT和新会话影响，不是纯网络量。实际决策使用固定候选/细化工作量，最终动作和完整工作计数一致。记录见 `results/cd2_route_health_20261003.json` 和 `cd2_route_decision_20261003.json`。这证明本机链路收益，尚不能证明平台所在地区或平台出网许可。
