# 全季空间支持函数：一个不依赖旧曝光列的上界路线

2026-10-03。这是待实现/复核的数学路线，不是新的全局最优证书。已实现的完整 target-slot 资源图见 `cold_probabilistic_resource_graph.py`；以下补回共同视场的一部分约束。

## 1. 从任意真实排程到乐观模型

目标 i 的 flux、science weight 记为 f_i、w_i，required 缺失罚为 P_i（普通目标取0），完成阈值为 τ，最大的 program 倍率为 M。

对每个真实天气时间段 k，构造 r_ik：任意合法曝光在该段中，目标 i 每单位观测时间能够获得的**原始 factor 信号上界**。单位可以统一为900秒。它必须包住官方评分器任意积分采样点，包括真实天气、可能的维修、增强事件、airmass、月光和曝光长度规则；只有正确构造 r，后面的代数才构成上界。

令 x_ik 是目标 i 在时间段 k 获得的纤维时间。真实的单次曝光 max factor 与 max science 都被把各次曝光信号累加后的乐观量 z_i 包住：

`0 <= z_i <= 1,  z_i <= sum_k r_ik x_ik`。

required 奖励阶跃有凹包络 `1{z_i>=τ} <= min(z_i/τ,1)`。因此真实科学分加 required 结算不超过

`sum_i R_i(z_i) - sum_i P_i`，其中 `R_i(z)=M w_i z + P_i min(z/τ,1)`。

这里允许跨曝光累计、自由选program、忽略数据失效，都是乐观放宽；原题仍是 best-only 结算。请求与报告另加其可证明的乐观奖励上界，Jain贡献上界为0。更强的单次曝光物理上限可把 z_i 的定义域由1收紧为 gmax_i，但必须证明不会漏合法曝光。

## 2. 共同视场的支持函数

对非负目标价格 ν_i，定义 H_k(ν)：在段 k 任意瞬间，一个共同 pointing 下至多16个不同目标的 `sum ν_i r_ik` 最大值。可以先放宽具体纤维格子和terrain，只保留共同视场及16个目标容量。真实曝光每个瞬间属于这个可行集，因此

`sum_i ν_i r_ik x_ik <= Δ_k H_k(ν)`，其中 Δ_k 是段 k 长度（同一时间单位）。允许瞬时无限切换视场只会放宽真实固定曝光。

对约束 `z_i <= sum_k r_ik x_ik` 做拉格朗日放宽，得到任意 ν_i>=0 下的上界

`U(ν) = sum_i max_{z in [0,1]} (R_i(z)-ν_i z) + sum_k Δ_k H_upper_k(ν) - sum_i P_i + REQ_upper + report_upper`。

R是分段线性的，目标项只需检查0、τ、1（若使用gmax则截断断点）。只要 H_upper 真正包住全部连续指向，U就是完整动作空间的乐观界；优化ν只决定界有多紧，不决定不等式是否成立。

## 3. 怎样包住所有连续 pointing

先从官方玻璃几何，得到角半径 R，使曝光开始时的合法 hit 都落在**实际视场中心**的球面圆帽内。官方offset是加到command后定义actual_center；覆盖所有实际中心即可包住它。不能把gnomonic矩形的半宽直接当球面半径。

官方玻璃只在曝光开始时判命中。支持函数应将当时的actual_center换算为固定RA/Dec：目标与该恒星坐标中心的角距在整次曝光保持不变，因此同一批assigned targets始终落在这个初始天区圆帽内。证明不要求它们在之后每一瞬间仍位于command对应的物理玻璃内。

用有限球面 cells 覆盖**整个可能的中心空间**。每个cell有代表点 c和经过证明的覆盖半径ρ。若真实中心在该cell内，它的所有目标必在 `distance(target,c)<=R+ρ` 的集合中。取这个集合中最大的16个非负 `ν_i r_ik` 之和，便是该cell的支持函数上界。对全部cells取max得到 H_upper_k。

球面RA/Dec矩形也可以构造保守cover radius：沿纬度/经度走折线路径，球面距离不超过两方向半宽之和；须包含南北极及RA接缝。更紧的球面三角形覆盖可减少候选并集。

可按cell上界细分，或批量GPU计算cell与目标的距离、top16支持值。保留未细分cell的上界可得到anytime证书；只有被可证上界排除的cell才能删掉。评估若只取目标锚点、已生成动作或几个随机中心，只能给支持函数下界，不能代入上式声称全局上界。

## 4. 实验与剪枝的采用门

1. 逐任意真实曝光嵌入的证明：共同视场、时间容量、评分采样规则及r上界全部成立。
2. 覆盖清单、半径证据、源文件SHA和数值向外容差可独立复核；数值证书与严格区间算术证明分开。
3. 所有已知强排程分数必须被包住，这是必要检查，不能代替上述证明。
4. 报告收紧前后上界、算力、每个空间放宽的代价；有限模型的最优值与原问题上界分开。
5. 只有给某个搜索分支构造了适用于它全部续局的U，且U不超过现有可行分，才可以据此剪枝。对部分排程还必须处理已知ledger和未来回溯失效，不能照搬从空季节推导的公式。

该路线同时提供全季时间/目标价格的研究对象，可作为候选搜索或NN的辅助教师。它尚未证明当前解接近全局最优，也尚未产生平台新分数。
