## 查重前初稿

### 1. 数学对象是条件整季干预优势

令 H 为部署时可见的完整历史，a 为合法候选动作，π 为动作之后实际执行的重规划策略。选择器应估计

`Aπ(H,a,b) = E[S_T | H, do(a), π] - E[S_T | H, do(b), π]`。

重点是干预后继续重规划；不是固定脚本的最终分数，也不是这个动作的即时得分。候选曝光会改变时刻、已观测状态、反馈、未来指向选择、observe 编号，以及 data_loss 失效区间。即使使用同一隐藏世界，后续行动和信息也可能不同。所谓单个世界中的优势 `Dω(H,a,b)` 是一次配对观察，不能直接宣称它等于条件期望。

最先应减少的学习负担是同一 H 下所有动作共享的季节基线。用同世界、同前缀的候选配对差分，标签满足 `D(a,b)=-D(b,a)`、`D(a,a)=0`，并能按五个官方得分分量逐项检查。若学习候选效用 u(H,a)，输出差 `u(H,a)-u(H,b)` 可自动保持这些约束。所有动作共享的偏置不影响选择。

### 2. 用官方结算器固定符号与权重

对同一前缀的 a、b 分支，精确路径差为

`Dω = ΔΣbest + P_req ΔN_required_completed + U ΔJ + Σ_r R_r Δ1{request r complete} + Δreport`。

这里 completed 增加取正号；最终 report 文件里的 required/uniformity 字段已经带负号，不可再次减。`best_i=max valid w_i g_i m_i` 与 `max_factor_i=max valid g_i` 必须分开；program 不替代因子阈值。请求只接受完整落在 `[issued_at, deadline]` 的有效曝光。data_loss 通过有效账本重算所有分量，时间不返还。最终分数直接学习会浪费容量记忆常数 `-P_req*N_required-U`，差分分量自动消去这些常数。

因此比无结构标量回归更稳的首个监督任务是**五项配对差分加解析求和**。required/request 的路径差是离散事件，标签应存完成数/完成事件而非只有总分；预测时可估计事件概率再乘官方固定权重。Jain 是唯一全局耦合项，应保留真实的 `ΔJ` 标签或 joint band sample；一般有 `E[J(r)] != J(E[r])`，不能把各条带的平均完成率代入后宣称精确期望。

### 3. 最有价值的残差是未来可补回机会，而不是即时质量误差

无失效且未来行动固定时，令 B_i 是当前有效最佳分，F_i 是未来可获得最佳分，当前动作给予 c_i。动作的科学边际价值为

`(c_i - max(B_i,F_i))_+`，而不是 `(c_i-B_i)_+`。

若 c_i 是确定值，则条件期望为

`∫[B_i,c_i] Pr(F_i < x | H,a,π) dx`。

若当前天气质量 c_i 与未来 F_i 有相关性，正确对象是

`∫[B_i,c_max] Pr(c_i > x, F_i < x | H,a,π) dx`。

这就是应该学习的“未来最佳值缺口”或联合越阈事件。好天气让即时动作高分，同时可能让未来替代机会也更好；将两个均值独立相乘可能把一个随时能补回的目标估成稀缺目标。required 的相应边际事件是“本动作过阈，未来未过阈”；若全季已经可靠过阈，其边际罚分收益为零。真实重规划中还要加上时间占用导致其他目标机会减少的负项。以上积分是用于解释残差的固定后续行动恒等式，不应把它误写成重规划分支精确解析式。

可部署的结构化残差策略：已有解析曝光效用算即时收益；学习 `整季配对差 - 解析即时配对差`，并按官方五项分解监督。在模型输入中同时提供两动作影响的目标、曝光时长、未来可见窗口、目标可替代候选数、deadline、剩余请求缺口及条带向量。残差允许为负；不能强行加 nonnegative 激活。解析误差和真正机会成本在此版本仍混合，若分叉数据能存首动作实际得分，可另存实际即时差以诊断两者。

### 4. 目标竞争必须显式表示

目标集合的无序聚合会丢失“这些目标竞争同一根光纤、同一片可见时间”的关系。同样数量、亮度、剩余可见时间的两个状态，若所有 required 目标只剩同一机会，其容量缺口远高于每个目标各有独占机会。应为候选建立目标—观测机会二部关系，用稀缺统计或小图表达：各目标剩余合格机会、唯一可行时段、每机会 required 需求/可用光纤、与当前动作共享/排斥的目标，以及小规模 Hall 缺口 `max(0, demand(U)-capacity(N(U)))`。不必求完整 DP；这里是一个可从公开几何和候选集计算的竞争表示。

最小实验应先给现有模型加入数个容量/竞争特征，而不是从训练 loss 决定使用超大模型。只有原表示能区分同边际统计、不同竞争拓扑的状态，才有理由保留该表示。极小合成判别探针可以证明需要关系输入；不能证明整季真实提分。

### 5. 部署历史中还有原始因子的可辨识问题

正式 last_result 仅返回 target_id 和 score，未返回 quality/factor/program 倍率。选定 program p 后，同一个 `c/w` 可能对应 `g=c/w`（不匹配）或 `g=c/(μ_p w)`（匹配）；必须保留可行因子集合/上下界，而不是把带 program 的 best 分数当原始 max factor。active_requests 的 completed_target_ids 为特定请求的真实阈值反馈；state_resync 的 best_scores 仍不返回 max factor。可观测历史中的未知 factor 与当前隐藏天气应共同进入 H 的信念摘要。这是监督标签可知与部署特征可知之间最容易产生的漏洞。

### 6. 优先级与验收

第一优先：配对分量、总分重构、符号校验、标签世界/前缀/候选/后续策略来源；第二优先：残差与目标竞争/信念特征；第三优先：才是容量扩大。每个 H 的候选之间共享隐藏世界属于配对，不能把每个候选或每个目标拆成独立训练样本后随机划分。跨完整前缀/卡/隐藏世界做验证，报告选错的整季分数损失和 deploy 回退率；训练 loss 仅作拟合诊断。若只有一个隐藏世界，先称为“该世界重规划排名监督”；需要条件于公开历史的多个相容世界或独立季节重现才能检验条件期望泛化。再运行完整季节才能接受为主策略。

初稿结论：普通 NN/树模型都可做候选优势的结构化残差；数据效率的主要来源是精确评分分解、配对消去基线、显式容量竞争和保持隐藏状态与动作相关性。PRO6000 能降低工程训练时间，但不能替代世界覆盖与分支定义。

## 查重与已完成的严格判别探针

### 保留现有正确工作，避免重复训练

查重已读 `ALGORITHM_PORTFOLIO_ZH.md`、`policy_iteration_model.md`、`structured_student_features.py/model.py/train.py` 与 `bulk_plan.json` 的计划内容；未打开 bulk captures、结果、标签或任何拟合文件。现有训练器已经进行真实后续重规划的配对监督、五项标签求和审计、整组/整卡划分、groupwise loss、regret 检查点选择、NumPy 部署隔离和单世界限制。这些均符合独立推导，应保留。初稿中的这些部分不是新路线。

本轮实质新发现是请求成员关系的信息丢失。模型源码的六个输出（总优势和五项辅助）没有预测求和约束，确实可作为将来结构化残差版本的设计选项，但单凭约束不能保证总优势或排序更准：对联合平方误差做正交投影可以降低联合误差，却可能增加其中的总分误差；当前使用 Huber loss，也不是该平方误差结论。因此不应立即以此替换现有模型，更不应重复训练既有 critic。

### 现有真实构建器的输入碰撞

`structured_student_features.py:226` 起逐目标汇总 request count、reward/remaining、remaining fraction、urgency、window factor estimate 与 public completed；请求成员身份随后不进入模型。`coarse_request_gain` 仅补充本动作立即把某请求完成时的奖励，无法表达“当前完成 i，未来可完成 j，而 i/j 是否属于同一请求”。

探针在同一公开目录 a,b,c,d、同一历史、同一动作候选上只改变公开请求图：

| 公开请求图 | 当前 control 观测 a，之后共同 π 观测 b | 当前 field 观测 c，之后共同 π 观测 b |
|---|---:|---:|
| Q1={a,b}, Q2={c,d} | 102.4 | 2.4 |
| Q1={a,d}, Q2={b,c} | 2.4 | 102.4 |

每请求需要两个不同成员过原始 factor 0.5，奖励100；所有目标属于同一个 RA band、science weight=1，合法开放曝光全饱和并匹配 DARK。两世界均有一个相同的关闭天气900秒 prefix，随后两个900秒开放曝光组成完整45分钟小域。未来 π 是相同的公开确定策略“下一次观测 b”。只研究这两个合法当前候选加共同 π；不是宣称整个连续动作空间的最优解。

已实际调用未经修改的 `build_public_features`，逐项 `np.array_equal` 通过：target_nodes `(4,44)`、global `(252,)`、flat `(2,584)`，两动作 target_index、edge `(1,17)`、scalar `(17,)`，以及 coarse/native 相关标量。模型读到的全部张量都相同，而最优候选相反。因此对任意参数的现有确定性模型，两状态预测相同；在两个状态等权时，其平均候选 regret 必为50分。随机化只能把损失分配到两边，不能突破50分。增加神经网络宽度、步数或 GPU 算力无法消除这个表示碰撞。

合法性和数值均由官方代码核对：`normalize_action` 接受完整 program 动作，FiberGrid 验证正确纤维命中且远离格缝，`min_altitude_during` 全程最低56.6778796178°，太阳在所有三个 slot 边界的最高高度为−20.4958948550°。`WeatherTruth.band_quality`、`score_target_exposure` 得到每个开放 hit 的原始 factor=1、score=1.2；`BestLedger`、required、Jain 与 observation request 结算给出表中精确结果。每条 schedule 的 science=2.4、required=0、uniformity=0、report=0；唯一差别是一个100分 request。未调用 `run_scenario`，未启动赛季模拟、训练、GPU、远端或网站操作。

### 最小补充：request 节点与成员关联

保留旧五模块源锁和现有固定比较。在版本化特征方案中新增以下两个对象即可保留当前缺失的信息：

1. 每个活动请求一个节点：`minimum_completed`、公开 completed count、deadline 距动作实际终点的余量、factor threshold、reward。
2. 请求—目标成员边：成员 target_index 只作 join，附公开 completed flag、本动作 assignment/eligibility、该动作 factor 预测；目标/请求 ID 不作为数值特征。

对每个 request 内部先聚合成员的目标特征及动作标记，应用 request 局部非线性，然后才汇总请求。不能把所有成员先并成一个全局平均，也不能只给每个 target 的 request 数量。建议保持小模型，或者先仅加入 request-local 可恢复成员计数/支持量；未来支持是公开几何或冻结行为策略的估计，必须标记为估计，不能使用未公开未来分叉真值。

同一探针已保存这个最小新增表示：两世界的 request nodes 相同，request_member_index 不同。已知共同 π 会观测 b，因此每个 request 内聚合 `本动作新成员数`、`π 未来成员数`、`两者重叠数`、`公开剩余缺口`，先做局部门槛再求和，得到两世界 control/field 奖励分别 `(100,0)` 与 `(0,100)`，恰好区分原碰撞。这里 b 的支持来自显式给定的公开 π，绝非标签输入；一般真实重规划的 π 支持仍需估计，不能直接假设未来会观测某目标。

### 范围与下一步

这是一个严格的信息丢失反例和低容量补充证明，不是 L1–L4 的收益证据。实际64个计划组含多少 active request 尚未统计，未据真实标签选择这个反例或参数。bulk 只有32训练状态，且只有两张训练卡的真实未来世界；不支持复杂图模型泛化声明。下一步应由 root 在旧版保持锁定的条件下，对新增关系表示做版本化扩展，先统计公开请求覆盖，接受标签后以同一预声明候选集比较，再通过完整部署赛季判断收益。
